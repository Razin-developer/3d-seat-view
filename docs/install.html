Install guide

Install it yourself in two minutes

3D Seat View is on its way to the Chrome Web Store. Until it is listed, you can load the same build by hand. It is free, and Chrome keeps it until you remove it.

Download ZIP Version 1.3.0 · about 200 KB · Chrome, Edge, Brave or Arc on a computer
  1. 1

    Download and unzip

    Download the ZIP above and unzip it. You get a folder named 3d-seat-view. Move it somewhere it will stay, such as Documents. Chrome loads the extension from this folder, so do not delete it.

  2. 2

    Open the Extensions page

    In Chrome, type this in the address bar and press Enter. Chrome does not allow websites to link to it, so copy it:

    chrome://extensions

    In Edge use edge://extensions, in Brave brave://extensions.

  3. 3

    Turn on Developer mode

    Use the switch in the top right corner of the Extensions page.

    Developer mode
  4. 4

    Load unpacked

    Three buttons appear at the top left. Click Load unpacked and choose the unzipped folder, the one that has manifest.json inside it.

    Load unpackedPack extensionUpdate
  5. 5

    Pin it

    Click the puzzle icon in the Chrome toolbar and pin 3D Seat View, so its icon is always visible.

    3D Seat View for BookMyShow & DistrictPin
  6. 6

    Use it

    Open a movie on BookMyShow or District and go to seat selection. Click the 3D Seat View icon, then click any seat. If the booking page was already open, reload it once.

Good to know

Is it safe to load an extension this way?

Loading unpacked is Chrome's built-in way to run an extension from a folder. This is the same build that is submitted to the Chrome Web Store. Nothing in it is hidden or compressed beyond the 3D library, so you can open and read every file in the folder before loading it. It runs only on BookMyShow and District pages. See the privacy policy.

Chrome shows "Disable developer mode extensions"

Chrome shows this reminder for every extension loaded from a folder. Close it and keep the extension on. It goes away once you install from the Chrome Web Store instead.

"Manifest file is missing or unreadable"

You picked the wrong folder. Choose the folder that directly contains manifest.json. If unzipping made a folder inside a folder, pick the inner one.

The panel says "No seat layout found"

Open a seat-selection page first, then reload that page once so the extension can read it.

How do I update or remove it?

To update: download the new ZIP, replace the folder's contents, then press the reload arrow on the extension's card on the Extensions page. To remove: press Remove on that card and delete the folder. When the Chrome Web Store version is out, remove this one and install from the store to get automatic updates.
